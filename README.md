# Desafio Dev Eficiente - Casa do Código

Desafio realizado usando as seguintes tecnologias:

- [Dotnet 9](https://learn.microsoft.com/pt-br/dotnet/core/whats-new/dotnet-9/overview)
- [Minimal Apis](https://learn.microsoft.com/pt-br/aspnet/core/fundamentals/minimal-apis/overview?view=aspnetcore-9.0)
- [MySql](https://www.mysql.com/)
- [FluentValidation](https://docs.fluentvalidation.net/en/latest/)

A organização do código segue a ideia de [Vertical Slicing](https://www.jimmybogard.com/vertical-slice-architecture/) que promove a divisão do código por features, não por camadas.
